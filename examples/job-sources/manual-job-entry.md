# Example: Manual Job Entry

Illustrates the fields captured when you add a job manually or paste a job description. This is
a planning example, not live data.

```
Title: Senior Backend Engineer
Company: Example Co
Location: Remote (Australia)
Source: manual
URL: https://example-co.com/careers/senior-backend-engineer
Status: interested

Description (pasted):
"""
We're looking for a Senior Backend Engineer to join our platform team...
Requirements: 5+ years Python, experience with FastAPI or similar, PostgreSQL...
"""

Notes: Recruiter mentioned range is 150-170k AUD; team is 6 engineers.
Follow-up date: (none yet)
```

See [`docs/application-workflow.md`](../../docs/application-workflow.md) for what happens to a
job after it's entered (ranking, application pack generation, status tracking).
